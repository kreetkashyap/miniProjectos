## 💡 Overview

This repository contains a series of **mini web apps** created as part of a personal learning journey in front-end development.  
Every project runs directly in the browser — no installations, frameworks, or build tools needed.

---
<a id="projects"></a>
## 🧩 Projects

| # | Project Name | Description |
|---|---------------|-------------|
| 1️⃣ | **Digital Clock** | Displays the current time dynamically with hours, minutes, and seconds. |
| 2️⃣ | **To-Do App** | Add, edit, and delete daily tasks. Data is saved in local storage. |
| 3️⃣ | **Form** | Interactive form that collects user info (Name, Email, Number, Roll, Job, T&C) and stores it in localStorage. Users can toggle to view submitted data. |
| 4️⃣ | **Tabs Component** | Simple tab navigation system for switching between content sections. |
| 5️⃣ | **Rock Paper Scissors** | Classic game against the computer with random choices and score tracking. |
| 6️⃣ | **Tic Tac Toe** | 3×3 game with win/draw detection and a reset feature. |
| 7️⃣ | **QR Code Generator** | Generates QR codes instantly from user-entered text or URLs. |
| 8️⃣ | **Drag and Drop** | Demonstrates HTML5 drag-and-drop interaction between elements. |

## 🚀 Getting Started

You can run any project locally in just a few seconds:

1. **Clone the repository**
   ```bash
   git clone https://github.com/kreetkashyap/miniProjectos.git
   ```

   
2. **Open the folder of the project you want**
```bash
cd miniProjectos/Digital-Clock
```


3. **Open the project**

- Double-click `index.html` file in the project folder to open it in your browser. 🎉
